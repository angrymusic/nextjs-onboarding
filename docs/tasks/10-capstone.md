# 과제 10. 종합 — 실제 프로젝트 미니 기능

## 목표

과제 1~9 종합 + 인수인계 진입. **이 학습 repo가 아니라 실제 인수인계 repo에서** 진행한다.

## 요구사항

- 멘토가 실제 repo에서 작은 기능 1개를 지정 (기준: 라우트 추가 + query 연동 + 테이블 또는 폼 1개, 가능하면 모달 포함)
- 기존 코드의 컨벤션을 먼저 읽고 그대로 따른다: 폴더 구조, queryKey 네이밍, 컴포넌트 분리 방식
- PR 제출 → 멘토 리뷰 → 머지 가능 수준까지 반복

## 완료 조건

- [ ] 실제 repo 컨벤션 준수 (리뷰에서 컨벤션 지적 0건이 목표)
- [ ] 서버/클라이언트 경계 판단을 스스로 함
- [ ] PR 설명에 "이 프로젝트에서 헷갈렸던 것" 목록 포함

## 체크 질문 (리뷰 겸 인수인계 인터뷰)

1. 이 기능에서 서버/클라이언트 경계를 어디에 그었고 왜인가?
2. queryKey 네이밍이 프로젝트 기존 컨벤션과 맞는가?
3. 이 프로젝트에서 제일 헷갈렸던 부분은? ← 인수인계 문서 보강 포인트로 수집
4. 지금 이 프로젝트를 혼자 유지보수한다면 제일 자신 없는 영역은? ← 후속 학습 결정
